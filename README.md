# Smart Clipboard - Text Reformatter

A powerful, feature-rich text formatting and manipulation tool built with vanilla HTML, CSS, and JavaScript. No dependencies, no frameworks, completely offline-capable.

![License](https://img.shields.io/badge/license-MIT-green)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
![HTML5](https://img.shields.io/badge/HTML5-100%25-orange)

## Features

### Whitespace Tools
- Remove extra spaces
- Remove trailing spaces
- Remove leading spaces
- Remove blank lines
- Trim every line

### PDF Cleanup
- Fix PDF line breaks
- Join wrapped sentences
- Preserve paragraph breaks

### Quote Conversion
- Convert smart quotes to straight quotes
- Convert smart apostrophes

### Bullet & Numbering
- Convert to dot bullets (•)
- Convert to asterisk bullets (*)
- Convert to dash bullets (-)
- Convert to numbered lists

### Case Conversion
- UPPERCASE
- lowercase
- Sentence case
- Title Case
- Toggle Case (InVeRt CaSe)

### Line Operations
- Sort lines A-Z
- Sort lines Z-A
- Reverse lines
- Remove duplicate lines
- Remove empty lines
- Number every line

### Text Cleanup
- Remove multiple tabs
- Replace tabs with spaces
- Replace multiple spaces with single space
- Normalize punctuation spacing
- Remove repeated punctuation

### URL Tools
- Remove UTM tracking parameters
- Decode URLs
- Encode URLs

### Find & Replace
- Simple find and replace
- Replace first occurrence
- Replace all occurrences
- Case-sensitive option

### Extra Features
-  Real-time statistics (characters, words, lines, reading time)
-  Copy to clipboard
-  Download as TXT file
-  Swap input and output
-  Undo/Redo functionality
-  Dark mode toggle
-  Keyboard shortcuts
-  Beautiful, responsive UI
-  Mobile-friendly design

## Statistics Tracked

- **Characters**: Total character count
- **Characters (no spaces)**: Character count excluding whitespace
- **Words**: Total word count
- **Lines**: Total number of lines
- **Paragraphs**: Number of paragraphs
- **Reading Time**: Estimated reading time (200 words/min)
- **Speaking Time**: Estimated speaking time (130 words/min)

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` or `Cmd+Z` | Undo |
| `Ctrl+Y` or `Cmd+Y` | Redo |
| `Ctrl+C` | Copy output (when focused) |
| `Ctrl+L` or `Cmd+L` | Clear input |
| `Ctrl+H` or `Cmd+H` | Open Find & Replace |
| `Esc` | Close Find & Replace modal |

## Quick Start

1. **Download or Clone**
```bash
   git clone https://github.com/yourusername/smart-clipboard.git
```

2. **Open in Browser**
   - Simply open `index.html` in any modern web browser
   - No installation or setup required
   - Works completely offline

3. **Start Using**
   - Paste text in the input area
   - Click any formatting button
   - See results in output area instantly
   - Copy, download, or swap as needed
